# wiki/ — WoW Classic AddOns

> **This project's compounding knowledge lives in the project repo's `docs/`**, not here. Because `itsginfo/wow-addons` is a personal repo that already version-controls its docs, duplicating them into a harness wiki would create two sources of truth. This stub exists to satisfy the template shape and to hold anything genuinely harness-side.

## What would go here
Harness-side narrative only (cross-session agent knowledge that isn't project code). `sources.md` logs external artifacts cited in sessions. Promote a topic to an entity page here only if it becomes harness-scoped rather than project-scoped.
